# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this
repository. Do not open a public issue.

We aim to acknowledge reports within 3 business days.

## Scope

This repository contains AI agent skills, prompts and helper scripts. Reports
we are especially interested in:

- a skill or script that could execute untrusted input, leak credentials, or
  take a destructive action without confirmation;
- any reference to non-public Solidgate infrastructure that slipped through
  review.

Vulnerabilities in Solidgate products are out of scope here; see
https://solidgate.com for product security contacts.
