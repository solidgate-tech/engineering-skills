# engineering-toolkit

Engineering practice that lives in the repository, next to the code.

| Skill | What it does |
|---|---|
| `architecture-decision-records` | Writes an ADR (Nygard / MADR style): one decision, its rationale, a "why not" for each alternative, and the consequences that get harder. |
| `software-design-document` | Writes a design document by interviewing you one decision at a time, with deferrals and a vertical-slice roadmap. |
| `setup-artifacts` | Sets up folders and `AGENTS.md` rules for AI artifacts (plans, specs, ideas, ADR/SDD indexes) and migrates existing records by moving, never rewriting. |

## Requirements

- `git`
- `glab` (optional): `setup-artifacts` can create `ADR` / `SDD` labels on GitLab projects
